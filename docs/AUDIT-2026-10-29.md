# Logos Ascension audit — 29 October 2026

This pass repairs presentation and audio behavior in the existing game. Combat rules, Heracles' War Cry balance, save format and multiplayer authority remain unchanged.

## Repairs and improvements

| Area | Finding | Change |
|---|---|---|
| Ground warning | Ground-wave events borrowed the sustained boss-cast cue. With no boss cast, the warning was silent; during a cast it could restart the wrong warning. | Independent ground warning, once per wave, preserving the boss charge. |
| Audio feedback | War Cry reused Provoke's short cue; phase and outcome events had no dedicated cue. | Original synthesized War Cry, phase/descent/awakening, victory and defeat cues. A shared compressor softens overlapping peaks. Existing music and saved volume settings remain; music defaults to 10%. |
| Audio lifecycle | An animation callback ran forever even with no sounds waiting. | Schedule frames only while contacts are queued; cancel on pause, mute, hide or unmount; resume interrupted contexts on a new gesture. Voice/queue limits remain in place. |
| Ground motion | Positions jumped at the simulation cadence and walk poses stopped between snapshots. | Interpolate presentation positions and facing each frame; derive stride from rendered movement. No combat-state mutation. |
| Dormant statues | Identical seated limbs recalculated inverse kinematics every frame. | Cache dormant poses until distortion/presentation conditions change. Root float and lighting continue, active poses always update. |
| Rendering | Results used full refresh; some idle refresh rates produced uneven cadence; soft shadows rendered every frame. | Stable 30 Hz idle/results cadence and 30 Hz soft-shadow updates, while combat/camera render at display cadence. Hidden tabs skip scene work; idle frames do not lower adaptive resolution. |
| UI workload | Paused local encounters cloned/rendered snapshots repeatedly; low graphics still blurred the canvas behind multiple panels. | Publish snapshots when simulation/state changes; omit costly blur, parallax and decorative filters in Performance mode. |
| Visual clarity | Reflective floor glare and noisy shadow contact; fixed phone HUD offsets overlapped variable-height boss warnings. | Rougher floor, adjusted shadow bias, natural-height portrait status stack, horizontally scrollable target strip and separated landscape target column. |
| Attachments | Weapon/hand samples repeated node searches, world-matrix updates and allocations. | Cache anchor identity and read the already-updated matrix directly. |

## Evidence

- Baseline: 458 passing tests. Revised code: **464 passing, 0 failing**; TypeScript check and production build exit 0.
- Regressions cover independent ground warnings, sound priority/deduplication, bounded voices and cleanup, zero idle audio scheduling, presentation-only movement interpolation, dormant-pose invalidation, and stable cadence at 60–165 Hz display intervals.
- One initial test failed because it compared a Three.js quaternion object/callback with a clone; corrected to numeric components. The initial failure log is retained.
- Real browser gameplay loaded all five painted heroes and the Logos rig with zero reported asset failures. War Cry spent MP and displayed its 12-second attack-speed effect and cooldown. A resumed dev encounter reached the Logos escape/victory screen.
- A clean production preview loaded, resumed a saved test encounter and played music (media readyState 4, not paused, no media error). Production module/style/model/animation/title/music load-path checks: **18 OK**.
- Portrait (390×844) and landscape (844×390) tests run in a desktop browser viewport, with 54px and 49px ability buttons respectively. These are responsive-layout checks, not physical-phone performance tests.

## Performance measurement and limits

A repeatable Node profile of six dormant sentinels, after 180 warm-up frames and over 1,200 measured frames, reduced median update cost from **0.379 ms to 0.070 ms** (81.5%) and p95 from **0.602 ms to 0.096 ms**. Redundant measured arm world-matrix updates fell from 14,400 to zero. This isolates the procedural-fallback CPU pose path; it is **not an overall FPS improvement or loaded-GLB/GPU benchmark**.

Representative local browser telemetry included 74 FPS in high-quality desktop Logos combat, 114 FPS in Performance portrait Crown combat and 103 FPS in Performance landscape Crown combat. Scene composition and run differ; these are observations, not an apples-to-apples comparison or universal 60-FPS promise. Pause/results target 30 FPS by design. Performance mode and the existing lighter character option remain available for slower devices.

Remaining limits: no physical mobile-device or Safari test, no multi-device online session/load test, and no human listening/mix acceptance. Sound routing and Web Audio graph/lifecycle were tested; this does not prove subjective audio quality. The existing large client-chunk build warning remains. Independent evidence review is pending; this report does not self-seal the work.
